# ito — クロスステッチ図案室

画像を端末内でマス目へ変換し、DMCの32色の近似パレットに減色します。PNG/JPEG/WebP（20MB以下）、目数・色数の設定、色の追加とマス編集、消しゴム、20段階の取り消し、図案SVG・運針CSVの出力、JSON保存・復元、端末内自動保存に対応します。

## 運針

同じ色の連続区間ごとに「／」を右へ刺し、「＼」で左へ戻ります。上糸を統一し、区間間は穴の距離3目以下なら裏側の移動、3目超なら糸始末・切断・再開を案内します。色の変更も糸始末を案内します。座標は左上(0,0)。1ステップは片方の斜めの針です。

これは初心者用の規則的な経路で、最短経路の最適化、裏糸の交差回避、手の状態や糸の残量の推定はしません。実際の布での運針の使いやすさは未検証です。通常のフルクロスのみ対応します。

## 色データ

DMC Mouliné Spécial の実在する32品番を収録。RGBは本アプリが用意した近似表示値で、メーカー公式の測色データではありません。全色には対応していません。購入は実物の色見本で確認してください。

- https://www.dmc.com/media/color_charts/DMC_Embroidery_Floss_Numerical_List_2021.pdf
- https://www.dmc.com/GB/en-GB/products/embroidery-thread-shade-card-printed

## 開発

Node 22.13以降。`npm install` / `npm run dev` / `npm run build`。
`node --experimental-strip-types --test tests/stitch.test.mjs` で運針の全マス被覆・斜線の順序・折り返し・移動・減色を検証します。`npx tsc --noEmit` で型検査します。

画像自体はアップロードせずブラウザ内で処理します。図案と運針位置はlocalStorageへ保存します。元画像は保存しないため、再読み込み後に目数・減色をやり直す際は再度画像を選択してください。図案を変更すると運針位置はリセットされます。透過領域は空白として扱います。大きい画像は縦横120目以内に収めます。

WebMCPは対応ブラウザで現在の運針を読む `read_stitch_guide` を公開します。対応コンテキストがないためWebMCP実行検証およびブラウザ操作テストは未実施です。
