# ito — クロスステッチ図案室

画像を端末内でマス目へ変換し、DMCの32色の近似パレットに減色します。画像自体はサーバーへ送信しません。

## ローカル起動・静的ビルド

Node 22.13以降。

```sh
npm install
npm run dev
```

http://localhost:3000/ で開きます。

```sh
npm run build
npm run start
```

`dist/` がGitHub Pagesに配置できる静的ファイルです。Viteの `base: './'` により、ドメイン直下にも `/リポジトリ名/` 以下にも配置できます。サーバー処理、Cloudflare、Sitesへの接続は実行時に不要です。今回の作業ではGitHub Pagesおよび既存Sitesへ公開しません。`.openai/hosting.json` は以前のSitesの識別情報として保持しますが、開発・ビルドには使いません。旧フレームワークの依存パッケージはロックファイルに保持しています。

## ドット文字

左側の「ドット文字を入れる」でＫＦひま字ドット／ノスタルドット M+H 10を選び、文字を入力します。文字サイズ、ドットの整数倍率、DMC糸色、左上からの列・行（1始まり）を指定し、プレビューを確認して「キャンバスに文字を入れる」を押します。改行にも対応します。

端末にインストールされたフォントを使用します。ブラウザがローカルフォントを読み込めない場合は、選択中のフォントに対応する `.otf` / `.ttf` をファイル欄から読み込んでください。ファイルは端末内で処理し、サーバーへ送信しません。フォントデータはリポジトリに同梱しません。読み込んだフォントはページを閉じるまで有効です。

文字のドットだけを既存の目に上書きし、空白は保持します。配置後は通常の図案として編集・保存・SVG/PDF出力・運針表示ができ、「一つ戻す」で取り消せます。保存するのは配置済みの目で、フォントや編集可能なテキストではありません。キャンバスに収まらない場合はサイズ・位置・文字数を調整してください。

## 図案と運針

- PNG/JPEG/WebP（20MB以下）を最大120×120目に変換
- 「自由に描く」で横・縦をそれぞれ1〜120目に指定して空のキャンバスを作成。最初は黒で描け、糸色も追加できます。作成前の図案には「一つ戻す」で戻せます。
- 目数・色数の設定、色の追加、マス編集、消しゴム、20段階の取り消し
- 図案の「余白を詰める」で外周の空白行・列を削除。白い糸や絵柄内の空白は維持し、「一つ戻す」で復元できます。保存・PDFにも詰めた寸法が反映されます。
- 「似た色をまとめる」で置き換え元と残す色を選び、図案全体の該当色を一括置換（対象マスの強調表示・変更目数・取り消しに対応）
- 図案SVG・PDF、運針PDFの保存、作業JSONの保存・復元
- 色ごとの運針一覧：全区間の配置・順番・折り返し・移動・切断位置をまとめて表示
- 各区間の下糸と上糸を並べ、すべての「出す穴」「入れる穴」に順番を表示
- 必要に応じて従来の一針ずつのガイドへ切り替え可能

同じ色の連続区間ごとに下糸「＼」を刺し、上糸「／」で折り返します。開始方向は左右から選びます。各区間の往復を完成してから次の区間に進みます。図案全体の下糸を先に刺す順番ではありません。

区間間の裏側の移動が3目以下なら移動、3目超なら糸始末・切断・再開を案内します。直前に入れた穴から再び針を出して糸が抜けないよう、必要な場合は下糸の出入りを反転します。斜線の向きは変わりません。色の変更時と最後にも糸始末を案内します。

座標は左上 (0, 0)。一針ガイドの1ステップは片方の斜線。色別一覧の穴番号はその色の1から始まり、奇数が出す穴、偶数が入れる穴です。

通常のフルクロスのみ対応します。区間の分割方法、区間内の往復方法は固定です。裏糸の交差回避、糸の残量の推定はしません。実際の布での使いやすさは未検証です。

## 保存

図案と一針ガイドの位置はlocalStorageに保存します。元画像は保存しないため、再読み込み後に目数・減色をやり直す際は再度画像を選択してください。図案を変更すると位置はリセットされます。

旧版の保存図案も復元できますが、経路最適化により順番が変わるため、旧版の運針位置は先頭に戻します。Sitesとlocalhostの保存領域は別です。サイト間で作業を移す場合はJSONを保存し、新しい画面で読み込んでください。

## 色データ

DMC Mouliné Spécial の実在する32品番を収録。RGBは本アプリが用意した近似表示値で、メーカー公式の測色データではありません。全色には対応していません。購入は実物の色見本で確認してください。

- https://www.dmc.com/media/color_charts/DMC_Embroidery_Floss_Numerical_List_2021.pdf
- https://www.dmc.com/GB/en-GB/products/embroidery-thread-shade-card-printed

## 検証

`npm test` で、全マスの斜線の被覆、下糸と上糸の方向、同一穴による糸の抜け防止、折り返し、区間分割と番号、移動、減色を検証します。`npm run lint` と `npx tsc --noEmit` で静的検査します。

WebMCPは対応ブラウザで現在の一針を読む `read_stitch_guide` を公開します。対応コンテキストがないためWebMCP実行検証およびブラウザ操作テストは未実施です。

## 経路の最適化

色ごとに、横に連続した区間を単位として、追いやすい順番を先に決め、その順番の中で左右の開始方向を最適化します。

- 上下左右で隣接する同色のマスを一つの領域とします。斜めに接するだけのマスは別領域です。
- 領域は最上段・左端の区間の順に訪問し、一つの領域を終えてから次へ進みます。
- 領域内は上から下、同じ段では左から右へ進みます。枝分かれ・合流がある場合も段順を維持します。短い区間を先に拾ったり、長い区間を後回しにしたりしません。
- この順番を固定し、各区間の左始まり・右始まりを動的計画法で選びます。目的は「切断回数」「裏糸の総距離」の順。実際の穴の位置と、糸抜け防止のための最初の斜線の反転も評価します。
- 区間間の3目を超える移動は切断し、その隙間は裏糸距離に含めません。区間内の裏糸も距離に含めます。糸の固定・始末に消費する長さは含めません。
- 方向の探索は区間数に比例する計算量です。区間数による方式切り替えや100区間ごとの分割はありません。固定した順番に対する方向は厳密最適ですが、全訪問順の中で切断回数・距離が最小になる保証はありません。段順を守るために切断や距離が増える場合があります。
- 最適化は内部で実行し、画面には運針のみを表示します。区間詳細は8目ずつ縦に並べ、内側のスクロールを使わずページ全体で閲覧します。

新しい図案は不変オブジェクトとして扱い、図案ごと・色ごとに計算結果をキャッシュします。一覧・一針表示・運針PDFは同じ経路を共有します。方向の総当たりとの一致、段順・領域の連続性、下糸と上糸の順序、穴の整合性をテストしています。運針バージョンは4とし、旧版の保存図案は維持しつつ、一針ガイドの位置を先頭へ戻します。

## PDFエクスポート

画面上部の「図案PDF」、または左側の「PDFで保存」から直接PDFをダウンロードできます。印刷ダイアログやサーバーは使いません。

- 図案PDF：全体図、34列×40段ずつの拡大図、記号・DMC番号・色名・目数の凡例。拡大図のセルは約5.3mmです。
- 運針PDF：全色または指定した色の全区間を、下糸／上糸に分けて掲載。出す穴は緑の丸と奇数、入れる穴は橙の四角と偶数。各図に座標・折り返し・移動／切断の説明を付けます。
- 長い区間は片道10目ずつ分割し、番号を維持して次の図・ページへ続けます。運針番号はアプリの色別一覧と共通です。
- A4、約192dpiの画像としてPDFへ格納するため、日本語フォントは端末のものを使用します。PDF内テキストの検索・選択には対応しません。
- 出力は作成開始時の図案を使用します。大きい図案の全色出力はページ数が多くなるため、色を指定して出力できます。

サンプルPDFを生成してページ画像の日本語・図案・運針の配置を検証済み。120目の単一区間で、ページをまたぐ480個の穴番号の欠落・重複がないことも確認しました。

## 画像変換モード

- イラスト向け（初期値）：各出力マスが覆う元画像領域について、面積と不透明度で重み付けした色の投票を行います。RGB各5bitの近似色グループから最多のグループを選び、その中のマス中心に最も近い元画素のRGBを使います。平均色を生成しません。透明部分の割合も考慮します。
- ドット絵向け：最近傍補間。既存のドットの色を混ぜません。
- 写真向け：Canvasの平滑化を有効にして縮小。ブラウザの高品質設定を使います。

イラスト向けの元画像読込みは長辺2048pxまで、最近傍で縮小してメモリを制限します。既に元画像に存在する中間色を除去する処理ではありません。細い線や小さい特徴が1マスより小さくなると、代表色方式でも消えることがあります。研究論文の輪郭と減色の同時最適化を再現したものではありません。

「近い色の小さな点を整理」は標準オフ。オンの場合、糸色変換後に1目または2目までの連結成分を調べ、図の端や透明領域に触れず、境界の80%以上が同じ色で、CIE Lab色差が12以下のものだけ周囲の色へ統合します。変更前の図案から判定するため、連鎖的な統合はしません。濃い目や口など色差の大きい特徴は整理対象から外します。

いずれも初回読込みと再変換で同じ処理を使います。設定を変更したら「この設定で図案を更新」を押してください。図案・運針位置は更新されます。
