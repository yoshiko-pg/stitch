# ito — クロスステッチ図案室

画像を端末内でマス目へ変換し、DMCの32色の近似パレットに減色します。画像自体はサーバーへ送信しません。

## ローカル起動・静的ビルド

Node 22.13以降。

```sh
npm install
npm run dev
```

http://localhost:3000/ で開きます。

```sh
npm run build
npm run start
```

`dist/` がGitHub Pagesに配置できる静的ファイルです。Viteの `base: './'` により、ドメイン直下にも `/リポジトリ名/` 以下にも配置できます。サーバー処理、Cloudflare、Sitesへの接続は実行時に不要です。今回の作業ではGitHub Pagesおよび既存Sitesへ公開しません。`.openai/hosting.json` は以前のSitesの識別情報として保持しますが、開発・ビルドには使いません。旧フレームワークの依存パッケージはロックファイルに保持しています。

## 図案と運針

- PNG/JPEG/WebP（20MB以下）を最大120×120目に変換
- 目数・色数の設定、色の追加、マス編集、消しゴム、20段階の取り消し
- 「似た色をまとめる」で置き換え元と残す色を選び、図案全体の該当色を一括置換（対象マスの強調表示・変更目数・取り消しに対応）
- 図案SVG、運針CSV、作業JSONの保存・復元
- 色ごとの運針一覧：全区間の配置・順番・折り返し・移動・切断位置をまとめて表示
- 各区間の下糸と上糸を並べ、すべての「出す穴」「入れる穴」に順番を表示
- 必要に応じて従来の一針ずつのガイドへ切り替え可能

同じ色の連続区間ごとに下糸「＼」を刺し、上糸「／」で折り返します。開始方向は左右から選びます。各区間の往復を完成してから次の区間に進みます。図案全体の下糸を先に刺す順番ではありません。

区間間の裏側の移動が3目以下なら移動、3目超なら糸始末・切断・再開を案内します。直前に入れた穴から再び針を出して糸が抜けないよう、必要な場合は下糸の出入りを反転します。斜線の向きは変わりません。色の変更時と最後にも糸始末を案内します。

座標は左上 (0, 0)。一針ガイドの1ステップは片方の斜線。色別一覧の穴番号はその色の1から始まり、奇数が出す穴、偶数が入れる穴です。CSVの手順番号は全色通しの一針番号です。

通常のフルクロスのみ対応します。区間の分割方法、区間内の往復方法は固定です。裏糸の交差回避、糸の残量の推定はしません。実際の布での使いやすさは未検証です。

## 保存

図案と一針ガイドの位置はlocalStorageに保存します。元画像は保存しないため、再読み込み後に目数・減色をやり直す際は再度画像を選択してください。図案を変更すると位置はリセットされます。

旧版の保存図案も復元できますが、経路最適化により順番が変わるため、旧版の運針位置は先頭に戻します。Sitesとlocalhostの保存領域は別です。サイト間で作業を移す場合はJSONを保存し、新しい画面で読み込んでください。

## 色データ

DMC Mouliné Spécial の実在する32品番を収録。RGBは本アプリが用意した近似表示値で、メーカー公式の測色データではありません。全色には対応していません。購入は実物の色見本で確認してください。

- https://www.dmc.com/media/color_charts/DMC_Embroidery_Floss_Numerical_List_2021.pdf
- https://www.dmc.com/GB/en-GB/products/embroidery-thread-shade-card-printed

## 検証

`npm test` で、全マスの斜線の被覆、下糸と上糸の方向、同一穴による糸の抜け防止、折り返し、区間分割と番号、移動、減色を検証します。`npm run lint` と `npx tsc --noEmit` で静的検査します。

WebMCPは対応ブラウザで現在の一針を読む `read_stitch_guide` を公開します。対応コンテキストがないためWebMCP実行検証およびブラウザ操作テストは未実施です。

## 経路の最適化

色ごとに、横に連続した区間を訪問する順番と左右の開始方向を最適化します。目的は辞書式で「切断回数」「裏糸の総距離」の順。区間間の3目を超える移動は切断し、その隙間は裏糸距離に含めません。区間内の裏糸も距離に含めます。糸の固定・始末に消費する長さは含めません。

- 10区間以下：訪問済み集合・終端区間・方向を状態とする Held–Karp 動的計画法。始点・終点自由の開いた経路です。この区間分割と往復ルールの範囲内で厳密最適。
- 11区間以上：最大12開始候補で貪欲探索し、方向変更で局所改善。100区間を超える場合は走査順の100区間ずつに分割して探索するため、離れた分割間の順序の最適化はしません。最適性の保証はありません。
- 最終的な評価が従来の走査順より悪ければ従来経路を採用。同値でも従来経路を維持します。
- 最適解／近似解の区別と、従来の切断回数・裏糸距離との比較を画面に表示します。

新しい図案は不変オブジェクトとして扱い、図案ごと・色ごとに計算結果をキャッシュします。一覧・一針表示・CSVは同じ経路を共有します。総当たりとの一致、下糸と上糸の順序、穴の整合性、近似法の非悪化をテストしています。

## PDFエクスポート

画面上部の「図案PDF」、または左側の「PDFで保存」から直接PDFをダウンロードできます。印刷ダイアログやサーバーは使いません。

- 図案PDF：全体図、34列×40段ずつの拡大図、記号・DMC番号・色名・目数の凡例。拡大図のセルは約5.3mmです。
- 運針PDF：全色または指定した色の全区間を、下糸／上糸に分けて掲載。出す穴は緑の丸と奇数、入れる穴は橙の四角と偶数。各図に座標・折り返し・移動／切断の説明を付けます。
- 長い区間は片道10目ずつ分割し、番号を維持して次の図・ページへ続けます。運針番号はアプリの色別一覧と共通です。
- A4、約192dpiの画像としてPDFへ格納するため、日本語フォントは端末のものを使用します。PDF内テキストの検索・選択には対応しません。
- 出力は作成開始時の図案を使用します。大きい図案の全色出力はページ数が多くなるため、色を指定して出力できます。

サンプルPDFを生成してページ画像の日本語・図案・運針の配置を検証済み。120目の単一区間で、ページをまたぐ480個の穴番号の欠落・重複がないことも確認しました。
